# Namirembe-cathedral-choir
The Namirembe Cathedral Choir Digital Platform is a Next.js 16 web app preserving a historic Anglican music legacy. It features 10 routes (`/about`, `/events`, `/media`, `/admin`), an interactive timeline, filterable events, media galleries, and join forms—all in brand green, black, and purple.
**Project Overview: Namirembe Cathedral Choir Digital Platform**

**Core Objective**
A modern, responsive, multi-page web application designed for the historic Namirembe Cathedral Choir. The platform preserves the choir's rich Anglican musical heritage, presents its leadership, communicates upcoming services and events, and provides engagement channels for public inquiries and choir applications.

**Key Features & Architecture**

* **Ecclesiastical Brand Identity:** Built with custom visual styling reflecting the choir's traditional colors (Forest Green `#1b4332`, Black `#0b090a`, Regal Purple `#5a189a`) paired with elegant typography.


* **Multi-Page App Router:** Scaffolded across 10 distinct routes (`/about`, `/history`, `/leadership`, `/music`, `/events`, `/media`, `/news`, `/join`, `/contact`, `/admin`).


* **Interactive Timeline & Media Centre:** Features an interactive historical roadmap documenting choir milestones alongside photo and video galleries with embedded YouTube media.


* **Event & Recruitment Workflows:** Interactive filterable event calendar (Services, Concerts, Rehearsals) and an integrated join application form for prospective choristers.


* **Admin Dashboard & Content Management:** Dedicated portal layout (`/admin`) designed for choir administration to oversee news, events, media updates, and application submissions.



**Technical Specifications**

* **Frontend Framework:** Next.js 16 (App Router, React, TypeScript)


* **Styling & UI Components:** Tailwind CSS, custom CSS variables, and responsive layout grids


* **Data Layer:** Centralized `data.ts` state structure ready for database integration (Supabase/PostgreSQL)
